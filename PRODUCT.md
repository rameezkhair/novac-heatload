# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

HVAC and MEP engineers in the UAE calculating building cooling loads.

## Product Purpose

NOVAC calculates room-by-room peak cooling loads and helps engineers review the results against relevant UAE building and ASHRAE standards.

## Positioning

A browser-based UAE-focused calculator combining ASHRAE CLTD/CLF calculations with local design conditions, psychrometrics, and code checks.

## Operating Context

Engineers enter project design conditions, envelope details, and room-by-room loads, then review the load schedule and compliance checks and generate a report. Work is saved in the browser or exported as a project file.

## Capabilities and Constraints

- Calculates sensible and latent loads and project totals.
- Includes design-condition inputs, envelope and room worksheets, psychrometric information, compliance checks, a load schedule, and reports.
- Supports project save/open, undo/redo, and schedule export.
- Project data stays in the user's browser unless they export a project file to share.
- Keep calculation behavior and existing project, schedule, compliance, and report features intact during interface changes.

## Brand Commitments

The product name is NOVAC. The product is made in the UAE. The calculator page should feel familiar to users of the existing landing page.

## Evidence on Hand

The codebase contains the calculator, standards library, and worked example. No customer testimonials or external product-performance claims are established.

## Product Principles

- Preserve calculation integrity.
- Make project inputs and results easy to review.
- Keep local project data under the user's control.
